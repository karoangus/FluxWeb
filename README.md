# FluxWeb

دانلودسنتر سبک و مستقل افزونه‌های وب، به زبان فارسی. وب‌سایت یک PWA ایستا و بدون کتابخانه، سرویس خارجی یا تحلیل‌گر است.

## اجرا و انتشار

برای اجرا در محیط محلی از ریشه مخزن `python3 -m http.server 8000` را اجرا کنید. برای نصب PWA باید سایت از HTTPS یا localhost ارائه شود؛ باز کردن مستقیم فایل HTML برای service worker کافی نیست. برای انتشار با GitHub Pages، در تنظیمات مخزن، Pages را روی Deploy from a branch و پوشه `/ (root)` از شاخه‌ای که می‌خواهید منتشر کنید قرار دهید. فایل‌ها از مسیر نسبی استفاده می‌کنند و برای مسیر زیرپوشه GitHub Pages نیز مناسب‌اند. فعال‌سازی Pages و آدرس نهایی به تنظیمات مخزن بستگی دارد. نصب PWA جدا از نصب افزونه کروم است و به پشتیبانی مرورگر بستگی دارد.

## Maz Lite — نسخه موجود و آزمایشی

فایل آماده: [`downloads/maz-lite-1.0.0-experimental.zip`](downloads/maz-lite-1.0.0-experimental.zip). این ZIP همان نسخه قبلی موجود در ریشه مخزن است، نه نسخه‌ای که بر اساس تحلیل عملکرد سایت بهینه شده باشد. تنظیمات مستقل ندارد. فقط در HTTPS دامنه `biomaze.ir` و زیردامنه‌های آن اجرا می‌شود. جاوااسکریپت، درخواست شبکه، ذخیره‌سازی و مجوزهای عمومی ندارد؛ اما CSS عمومی آن انیمیشن، transition، سایه و backdrop-filter را تغییر می‌دهد و می‌تواند ظاهر یا رفتار سایت را مختل کند. سازگاری با آزمون و بهبود عملکرد سنجیده نشده است؛ در آزمون‌های مهم استفاده نکنید. در صورت بروز مشکل افزونه را خاموش و صفحه را دوباره بارگذاری کنید.

### نصب افزونه در Chrome

1. ZIP را دانلود و استخراج کنید.
2. `chrome://extensions` را باز کرده و Developer mode را روشن کنید.
3. Load unpacked را انتخاب کنید و پوشه `maz-lite-extension` (پوشه حاوی `manifest.json`) را باز کنید.
4. صفحه سایت را تازه‌سازی کنید. از همان صفحه افزونه‌ها می‌توانید افزونه را خاموش یا حذف کنید.

## محدودیت‌های بررسی

دسترسی مستقیم به سایت هدف در محیط توسعه ممکن نبود؛ selector معتبر و داده Performance از پنل و آزمون در دسترس نیست. بنابراین هیچ بهینه‌سازی هدفمند یا ادعای بهبود سرعت به نسخه موجود اضافه نشده است. برای ادامه به آدرس صفحات مشکل‌دار، نمونه Elements/CSS و ضبط Performance بدون اطلاعات شخصی نیاز است.

## ساختار

- `index.html`, `styles.css`, `app.js`: رابط دانلودسنتر
- `site.webmanifest`, `sw.js`, `assets/`: قابلیت نصب و کش آفلاین وب‌اپ
- `downloads/`: فایل قابل دانلود افزونه
- `manifest.json`, `maz-lite.css`, `راهنمای-نصب.txt`: فایل‌های اصلی نسخه موجود افزونه
