# FluxWeb

دانلودسنتر مستقل افزونه‌های وب، به زبان فارسی. وب‌سایت یک PWA ایستا و بدون کتابخانه، سرویس خارجی یا تحلیل‌گر است.

## اجرا و انتشار وب‌اپ

برای اجرا در محیط محلی از ریشه مخزن `python3 -m http.server 8000` را اجرا کنید. برای نصب PWA باید سایت از HTTPS یا localhost ارائه شود؛ باز کردن مستقیم فایل HTML برای service worker کافی نیست. این پروژه برای GitHub Pages از شاخه اصلی و پوشه ریشه آماده است و از مسیرهای نسبی استفاده می‌کند. نصب PWA جدا از نصب افزونه Chrome است و به پشتیبانی مرورگر بستگی دارد.

## Maz Lite 1.1.0 — آزمایشی

[دانلود ZIP نسخه ۱.۱](downloads/maz-lite-1.1.0-experimental.zip) · [فایل‌های افزونه](extensions/maz-lite/) · [دانلود نسخه قبلی ۱.۰](downloads/maz-lite-1.0.0-experimental.zip)

نسخه ۱.۱ یک پنل سبک برای کنترل مستقل کاهش انیمیشن، کاهش transition، حذف سایه عناصر، حذف سایه متن، حذف backdrop blur و حذف اسکرول نرم CSS دارد. دکمه اصلی همه گزینه‌ها را موقتاً خاموش می‌کند، بدون از دست رفتن تنظیمات جداگانه؛ دکمه بازگشت، همه گزینه‌ها را به پیش‌فرض برمی‌گرداند. حالت اولیه مانند ۱.۰ همه این تغییرات را فعال می‌کند، چون کاربر از روان‌تر شدن نسخه قبلی و ندیدن مشکل در استفاده خودش گزارش داده است. این گزارش جایگزین اندازه‌گیری یا تست سازگاری نیست.

**محدودیت مهم:** به علت نبود selectorهای تأییدشده، قوانین همچنان سراسری‌اند و نسخه جدید هدفمند به بخش‌های خاص سایت نیست. ممکن است ظاهر یا رفتار سایت، از جمله آزمون، تغییر کند. نسخه ۱.۱ روی سایت واقعی یا آزمون آزمایش نشده و بهبود سرعت آن اندازه‌گیری نشده است؛ در آزمون مهم از آن استفاده نکنید. در صورت بروز مشکل افزونه را خاموش و صفحه را تازه‌سازی کنید. تغییر تنظیمات در تب‌های باز ماز اعمال می‌شود؛ ممکن است بعضی تغییرات سایت تنها پس از تازه‌سازی صفحه برگردند.

افزونه فقط در HTTPS دامنه `biomaze.ir` و زیردامنه‌های آن اجرا می‌شود و از مجوز `storage` برای ذخیره تنظیمات در `chrome.storage.local` استفاده می‌کند. افزونه سرویس خارجی، درخواست شبکه، کتابخانه خارجی و background service worker ندارد. نسخه ۱.۰ بدون تغییر در ریشه مخزن و ZIP جداگانه باقی مانده است.

### نصب افزونه در Chrome

1. ZIP نسخه دلخواه را دانلود و استخراج کنید.
2. `chrome://extensions` را باز و Developer mode را روشن کنید.
3. Load unpacked را انتخاب و پوشه `maz-lite-extension` حاوی `manifest.json` را باز کنید.
4. اگر نسخه قبلی را نصب کرده‌اید، آن را خاموش یا حذف کنید تا هر دو هم‌زمان اعمال نشوند. صفحه ماز را تازه‌سازی کنید.
5. از منوی افزونه‌های Chrome، Maz Lite را پین کنید و روی آیکون آن بزنید تا تنظیمات باز شود. برای غیرفعال‌کردن کامل می‌توانید از صفحه افزونه‌های Chrome هم استفاده کنید.

## بررسی و تست

دسترسی مستقیم به سایت هدف در محیط توسعه ممکن نبود. selector معتبر و داده Performance از پنل و آزمون در دسترس نیست؛ بنابراین نسخه ۱.۱ صرفاً قابل‌کنترل‌تر است، نه بهینه‌سازی هدفمند یا بهبود سرعت اثبات‌شده. تست‌های خودکار شبیه‌سازی‌شده را با `node tests/maz-lite.test.js` اجرا کنید. این تست‌ها جایگزین تست واقعی در Chrome یا سایت نیستند.

## ساختار

- `index.html`, `styles.css`, `app.js`: رابط دانلودسنتر
- `site.webmanifest`, `sw.js`, `assets/`: نصب و کش آفلاین وب‌اپ
- `downloads/`: فایل‌های ZIP قابل دانلود
- `extensions/maz-lite/`: سورس نسخه آزمایشی ۱.۱
- `manifest.json`, `maz-lite.css`, `راهنمای-نصب.txt`: فایل‌های اصلی نسخه ۱.۰
- `tests/`: تست‌های بدون وابستگی
